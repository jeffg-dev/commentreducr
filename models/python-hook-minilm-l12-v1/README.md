# Python documentation classifier

This is the frozen INT8 MiniLM-L12 model used by reduction and the Git hook in every build.
It predicts PASS or FLAG for an entire Python comment/docstring block. Any
unnecessary passage makes the block FLAG. Comments need an unexpected reason,
a non-obvious trap, or a shortcut through complex code. Docstrings describe the
consumer contract and keep implementation details closed.

The base encoder is
[Microsoft MiniLM-L12-H384-uncased](https://huggingface.co/microsoft/MiniLM-L12-H384-uncased),
revision `44acabbec0ef496f6dbc93adadea57f376b7c0ec`, under the included Microsoft MIT
license. Fine-tuning used independently invented Python examples generated by
Claude Sonnet and explicitly labeled by GPT-6.1-sol. No private source code,
comment text, identifiers, paths, or screenshots were included in training.

`model.onnx` contains 34,168,774 bytes. Its SHA-256 is:

```
d61e7db485fdc3cae445e674194b528fa424d118320845d8a24b0c67781e4442
```

The tokenizer and classifier settings are packaged in `src/model/`. The fixed
FLAG threshold is `0.9450385272502899`, with a 384-token input budget. Inputs are
the documentation kind, complete target text, and code context. Context alone
can be truncated; oversized targets are reported for manual review. Every block
runs independently, as required by the export's dynamic quantization policy.

The native CPU implementation was checked against 456 frozen Python-runtime
reference predictions: 455 decisions agreed. The remaining decision was an
additional false flag; CPU runtime builds produced different numeric scores.
The weights, tokenizer, rubric, and threshold were unchanged. The installer
therefore uses author-feedback warning mode.

`install-git-hook` downloads this versioned model into the user's cache and verifies
its checksum. Model binaries are excluded from the crates.io package.
